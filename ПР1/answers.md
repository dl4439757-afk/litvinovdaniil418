# Практическая работа №1: Работа с Git

## Ответы на вопросы

1. Три области: рабочая папка (редактируемые файлы), индекс (staging area, подготовка к коммиту), репозиторий (история коммитов).
2. git add — добавляет изменения в индекс; git commit — фиксирует изменения в репозитории; git push — отправляет коммиты на удалённый репозиторий.
3. Информативные сообщения помогают понять историю изменений, облегчают поиск ошибок и совместную работу.
4. git add имя_файла добавляет конкретный файл, git add . — все изменения в текущей директории.
5. git status показывает состояние рабочей папки и индекса: изменённые, добавленные, неотслеживаемые файлы.
6. git remote add origin URL привязывает удалённый репозиторий с именем origin. origin — стандартное имя основного удалённого репозитория.
7. Флаг -u связывает локальную ветку с удалённой, после чего можно использовать git push без параметров.
8. Ветка по умолчанию сейчас main (раньше master). Это важно для синтаксиса команд.
9. git log показывает историю коммитов: хеш, автор, дата, сообщение.
10. Если не сделать git add перед commit, изменения не попадут в коммит.
