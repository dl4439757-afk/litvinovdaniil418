# ПР5 - Ответы

1. display: grid включает Grid, работает в 2D (строки и столбцы).
2. grid-template-columns для явной сетки, grid-auto-columns для неявной.
3. repeat() повторяет, minmax() задаёт диапазон, auto-fit растягивает.
4. Именованные области упрощают размещение элементов.
5. grid-column и grid-row размещают по линиям.
6. gap чище margins, не создаёт внешних отступов.
7. justify-items по главной оси ячейки, align-items по поперечной.
8. auto-fill оставляет пустые треки, auto-fit растягивает.
9. grid-template-areas создаёт схему макета.
10. Grid мощнее для 2D-макетов.
