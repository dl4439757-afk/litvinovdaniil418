# ПР4 - Ответы

1. display: flex включает Flexbox, дочерние становятся flex-элементами.
2. justify-content по главной оси, align-items по поперечной.
3. flex-direction задаёт направление: row, column, row-reverse, column-reverse.
4. flex: 1 = flex-grow:1, flex-shrink:1, flex-basis:0%.
5. flex-wrap переносит элементы на новую строку.
6. align-content для многострочных контейнеров, align-items для одной строки.
7. order меняет порядок элементов.
8. main axis задаётся flex-direction, cross axis перпендикулярна.
9. flex-wrap + flex-basis для адаптивности без медиа.
10. gap чище, чем margins.
