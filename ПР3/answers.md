# ПР3 - Ответы

1. Класс можно использовать многократно, ID уникален и имеет выше специфичность.
2. Каскад: важность, специфичность, порядок.
3. ul li.important = 0,1,2; #site-title = 1,0,0; .content > .featured-post = 0,2,0.
4. Наследуются: color, font-family, line-height. Не наследуются: margin, padding, border.
5. > выбирает только прямых потомков, пробел - всех потомков.
6. :hover для интерактивности, :nth-child для чередования.
7. !important переопределяет всё, использовать осторожно.
8. ::before и ::after добавляют контент через content.
9. При равной специфичности применяется последнее правило.
10. DevTools показывают применённые стили и специфичность.
